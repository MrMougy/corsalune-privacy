# corsalune-privacy
Politique de confidentialité officielle du jeu Corsalune

Site public : https://mrmougy.github.io/corsalune-privacy/

Page statique française, sans JavaScript, dépendance externe, cookie ajouté ou suivi analytique. Le CSS est inclus dans `index.html`.

Publication GitHub Pages depuis `main`, dossier `/` (racine). `.nojekyll` désactive le traitement Jekyll. L'audit et ses limites sont documentés dans [AUDIT.md](AUDIT.md).

Avant toute évolution du jeu, vérifier les SDK, permissions, sauvegardes et transmissions, puis mettre à jour la politique et sa date. Ne jamais ajouter de coordonnées non confirmées.
